# 株式会社HIBURI 部門権限マトリックス

## 概要

社長の意思決定負荷を軽減し、部門長が自律的に動けるよう、決裁権限を4段階で定義します。

## 権限レベル

| レベル | 記号 | 決裁者 | 説明 |
|--------|------|--------|------|
| **レベルA** | :diamonds: | **社長決裁** | 経営方針・大型投資・重要契約など |
| **レベルB** | :large_blue_diamond: | **秘書協議→社長報告** | 部門横断案件・中規模の判断 |
| **レベルC** | :small_orange_diamond: | **部門長判断→秘書報告** | 通常業務の範囲内の判断 |
| **レベルD** | :small_blue_diamond: | **部門長権限** | 日常業務・定例対応 |

## 運用ルール

1. **権限レベルを超える判断は絶対にしない** - 不明な場合は上位レベルとして扱う
2. **緊急時は即座に社長に報告** - 危機レベル3以上は権限レベルに関わらず社長決裁
3. **金額基準** - 10万円以上の支出は社長決裁、10万円未満は秘書協議
4. **報告義務** - レベルC以上は必ずSlackで社長に報告する
5. **逆提案の権利** - 部門長は社長の指示に対して代替案を提示できる（最終判断は社長）
