# ナレッジベース

AI部門長の長期学習を実現するため、組織の知見を蓄積するディレクトリです。
部門長（Agent）への指示時に、関連するナレッジを参照させてください。

## ディレクトリ構成

```
knowledge-base/
├── decisions/          # 重要な意思決定の記録
│   └── YYYY-MM-DD_[件名].md
├── incidents/          # インシデント・障害の記録と対策
│   └── YYYY-MM-DD_[件名].md
├── best-practices/     # 成功事例・ベストプラクティス
│   └── [カテゴリ]_[件名].md
└── meeting-notes/      # 会議・ミーティングの議事録
    └── YYYY-MM-DD_[会議名].md
```

## 記録テンプレート

### 意思決定記録（decisions/）
```markdown
# [件名]
日付: YYYY-MM-DD
担当部門: [部門名]
決裁者: 社長 / 部門長

## 背景
## 選択肢
## 決定事項
## 理由
## 想定リスク
```

### インシデント記録（incidents/）
```markdown
# [件名]
日付: YYYY-MM-DD
危機レベル: 1-4
担当部門: [部門名]

## 発生内容
## 原因
## 対応内容
## 再発防止策
## 教訓
```
