## 地域密着型ビジネスのための統合マーケティングソリューション

---

**提案先**: クリニック・美容院・飲食店等の中小企業経営者様
**作成日**: 2026年3月13日
**作成**: 株式会社HIBURI 営業部

## 1. 対象顧客像

本提案書は、以下のような課題をお持ちの経営者様に向けたものです。

- **クリニック**（歯科・皮膚科・美容クリニック等）: 新規患者の獲得、自費診療の認知拡大
- **美容院・エステサロン**: リピーター育成、新規集客、ブランドイメージ構築
- **飲食店・カフェ**: 来店促進、テイクアウト/デリバリー認知、地域での存在感向上
- **その他地域密着型ビジネス**: 学習塾、ジム、不動産仲介など

**共通する特徴**:
- 商圏が半径3〜10km圏内
- 月間広告予算 10万〜100万円規模
- 専任マーケティング担当者がいない
- 「やった方がいいのは分かるが、何から始めればいいか分からない」

## 2. 中小企業のマーケティング課題

### 2-1. デジタル広告だけでは届かない層がいる

WEB広告（リスティング、SNS広告）は効率的ですが、**スマホを見ていない時間帯の生活者**には届きません。通勤中・買い物中・散歩中の潜在顧客は、デジタル広告だけではカバーできません。

### 2-2. 看板・OOH広告は「やりっぱなし」になりがち

従来のOOH（屋外広告）は大手企業向けの料金体系で、中小企業が手を出しにくい領域でした。また、効果測定が困難で「出してはみたが、成果が見えない」という状態に陥りがちです。

### 2-3. 各施策がバラバラで相乗効果が生まれない

WEB広告はA社、チラシはB社、看板はC社——と別々の業者に依頼すると、メッセージやクリエイティブに統一感がなく、**ブランドとしての印象が分散**してしまいます。

### 2-4. エンタメ的な仕掛けは大手の特権だと思われている

イベント企画やインフルエンサー活用は、予算が潤沢な大手企業だけのものと思われがちです。しかし、地域密着型だからこそ効果的な**小規模エンタメ施策**が存在します。

### 課題の要約

| 課題 | 現状 | 本来あるべき姿 |
|------|------|---------------|
| デジタル偏重 | WEB広告のみ | オンライン × オフラインの統合 |
| OOH未活用 | 高コスト・効果不明 | 中小企業でも使えるDOOH/OOH |
| 施策の分散 | 業者バラバラ | 一貫したブランドメッセージ |
| エンタメ未活用 | 大手の特権 | 地域密着型エンタメ施策 |

## 3. HIBURIの解決策 — 3本柱の統合マーケティング

### HIBURIだけの強み

**WEB広告 × DOOH/OOH × エンターテインメント**を中小企業向けに統合提供できるのは、HIBURIだけです。

競合他社はいずれも「デジタル完結型」「大手プラットフォーム中心」「大手専用」のいずれかに偏っており、**中小企業が手の届く価格帯で3領域を一気通貫で提供する企業は他にありません**。

### 第1の柱: WEB広告（デジタルマーケティング）

- **YouTube広告**: 動画で信頼感を醸成。院内紹介・施術Before/After・メニュー紹介等
- **Google/Yahoo!リスティング広告**: 「地域名 × 業種」で検索する顕在層を確実に捕捉
- **SNS広告（Instagram/TikTok）**: ビジュアル訴求で20〜40代女性にリーチ
- **MEO対策**: Googleマップ上での上位表示で来店導線を確保

### 第2の柱: DOOH/OOH（デジタル屋外広告・屋外広告）

- **駅・商業施設のデジタルサイネージ**: 商圏内の生活者に日常的に接触
- **交通広告（バス・タクシー）**: 通勤・通院動線上で繰り返しリーチ
- **店舗周辺ポスター・のぼり**: 近隣住民への直接的な認知獲得
- **効果測定との連動**: WEB広告のクリック率変化と連動分析し、OOHの効果を可視化

### 第3の柱: エンターテインメント施策

- **地域イベント企画・協賛**: 地元のマルシェ・フェスへの出店支援
- **マイクロインフルエンサー活用**: 地域密着型のインフルエンサー（フォロワー1,000〜10,000人）を起用
- **店舗体験コンテンツ**: SNS映えする店内フォトスポット、体験型キャンペーン
- **コラボ企画**: 近隣店舗とのスタンプラリー、相互送客施策

### 統合による相乗効果

```
  ┌─────────────┐
  │  WEB広告で   │──→ 認知・検索
  │  興味喚起    │
  └──────┬──────┘
         │ ×
  ┌──────▼──────┐
  │  DOOH/OOHで  │──→ 日常接触・信頼蓄積
  │  反復リーチ  │
  └──────┬──────┘
         │ ×
  ┌──────▼──────┐
  │ エンタメで   │──→ 来店・体験・口コミ拡散
  │ 行動を促進   │
  └─────────────┘
```

**単体では点の施策**が、統合することで**面の戦略**に変わります。

## 4. 導入効果（期待される成果）

### 定量的な期待効果

| 指標 | 導入前（目安） | 導入6ヶ月後（目標） |
|------|--------------|-------------------|
| 月間新規問い合わせ数 | 10〜20件 | 30〜50件（1.5〜2.5倍） |
| WEB経由の来店/来院率 | 5〜10% | 15〜25% |
| 地域内認知度 | 低い | 商圏内生活者の30%以上が認知 |
| リピート率 | 30〜40% | 50〜60% |
| 広告費用対効果（ROAS） | 不明 | 300%以上を目標 |

※業種・立地・既存の集客状況により変動します。

### 定性的な期待効果

- **ブランド統一感の向上**: オンライン・オフライン・イベントすべてで一貫したメッセージ
- **業務負荷の軽減**: 複数業者との調整が不要。HIBURIが一括マネジメント
- **データに基づく改善**: 毎月のレポートで「何が効いているか」が可視化される
- **地域での存在感**: 「あのお店、最近よく見るね」という日常的な認知の蓄積

## 6. 導入スケジュール

### Phase 1: 準備期間（契約後 1〜2週間）

| 項目 | 内容 |
|------|------|
| キックオフMTG | 現状ヒアリング、ターゲット設定、KPI設定 |
| 競合・商圏分析 | 商圏内の競合状況・生活者動線を調査 |
| アカウント開設 | Google/SNS等の広告アカウント整備 |
| クリエイティブ方針 | ブランドメッセージ・トンマナの策定 |

### Phase 2: 立ち上げ期（3週目〜1ヶ月目）

| 項目 | 内容 |
|------|------|
| WEB広告配信開始 | リスティング広告・MEO対策を先行スタート |
| クリエイティブ制作 | バナー・動画・OOH素材の制作 |
| 効果測定基盤構築 | コンバージョン計測・レポートテンプレート整備 |

### Phase 3: 拡大期（2〜3ヶ月目）

| 項目 | 内容 |
|------|------|
| OOH/DOOH配信開始 | スタンダード/プレミアムプラン対象 |
| SNS広告追加 | 初月のデータを基に媒体・ターゲット最適化 |
| 初回月次レポート | 数値振り返り + 改善提案 |

### Phase 4: 最適化期（4〜6ヶ月目）

| 項目 | 内容 |
|------|------|
| エンタメ施策実施 | イベント企画・インフルエンサー施策の実行 |
| PDCA本格運用 | A/Bテスト、クリエイティブ改善、予算配分最適化 |
| 6ヶ月レビュー | 成果総括 + 次期戦略提案 |
