# 株式会社HIBURI SNS運用戦略（3ヶ月計画）

**作成日**: 2026-03-13
**担当部門**: マーケティング部
**権限レベル**: C（部門長判断 → 秘書報告）
**対象期間**: 2026年4月〜6月

---

## 1. ターゲットペルソナ

### ペルソナA: 集客に悩むクリニック院長

| 項目 | 詳細 |
|------|------|
| 年齢・性別 | 40代男性 |
| 業種 | 美容皮膚科・歯科クリニック |
| 売上規模 | 年商5,000万〜2億円 |
| 課題 | 開業3年目で新規患者が伸び悩み。Web広告は試したが費用対効果が見えない |
| 情報収集 | Instagram、YouTube、業界セミナー |
| 決裁パターン | 自分で即決。ただし費用対効果の根拠を重視 |
| HIBURIへの期待 | 少額から始められるクロスメディア施策で、地域からの来院数を増やしたい |

### ペルソナB: 多店舗展開を目指す美容サロンオーナー

| 項目 | 詳細 |
|------|------|
| 年齢・性別 | 30代女性 |
| 業種 | ヘアサロン・ネイルサロン（1〜3店舗） |
| 売上規模 | 年商3,000万〜1億円 |
| 課題 | SNSは自力運用しているがフォロワーが伸びない。2店舗目出店に向けブランディングを強化したい |
| 情報収集 | Instagram、TikTok、同業オーナーの口コミ |
| 決裁パターン | 感覚と実績の両方を見る。成功事例に強く反応 |
| HIBURIへの期待 | SNS運用代行＋地域広告で認知を一気に拡大したい |

### ペルソナC: デジタル施策に踏み出したい飲食店経営者

| 項目 | 詳細 |
|------|------|
| 年齢・性別 | 50代男性 |
| 業種 | 居酒屋・レストラン（個人経営〜3店舗） |
| 売上規模 | 年商2,000万〜8,000万円 |
| 課題 | グルメサイト依存から脱却したいが、何から始めていいかわからない |
| 情報収集 | Facebook、LINE、テレビ・新聞 |
| 決裁パターン | 慎重。小さく試して効果を確認してから拡大 |
| HIBURIへの期待 | 手間をかけず、低予算で集客できる仕組みを作ってほしい |

## 2. 使用プラットフォーム選定と理由

### 主力プラットフォーム

| プラットフォーム | 優先度 | 選定理由 |
|-----------------|--------|----------|
| **Instagram** | ★★★ | ペルソナA・Bの主要接触メディア。ビジュアル訴求でクリニック・サロンの施策事例を見せやすい。Reelsで短尺動画も対応可能 |
| **TikTok** | ★★☆ | 30代以下への認知拡大に有効。DOOH/OOH施策との親和性が高く、「街中で見かけた広告」系コンテンツが拡散しやすい |
| **YouTube** | ★★☆ | 中長尺の事例紹介・ノウハウ解説でペルソナAの信頼獲得。検索経由の長期流入が見込める |

### 補助プラットフォーム

| プラットフォーム | 優先度 | 選定理由 |
|-----------------|--------|----------|
| **LINE公式アカウント** | ★★☆ | ペルソナCの主要接触メディア。リード獲得後のナーチャリング・CRM用途 |
| **X（旧Twitter）** | ★☆☆ | 業界ニュース発信・リアルタイム情報共有。運用工数を抑え、Instagramコンテンツの転用で対応 |

### 非採用プラットフォーム

| プラットフォーム | 理由 |
|-----------------|------|
| Facebook | ペルソナの利用率が低下傾向。リソースを集中するため初期は非採用 |
| LinkedIn | BtoB大企業向け。HIBURIのターゲット（中小企業経営者）とは接点が薄い |

## 3. コンテンツカテゴリと投稿頻度

### コンテンツカテゴリ

| カテゴリ | 内容 | 目的 | 比率 |
|----------|------|------|------|
| **成功事例** | クライアントのビフォーアフター、数値成果 | 信頼獲得・リード転換 | 30% |
| **ノウハウ** | 中小企業向け集客Tips、広告の基礎知識 | 専門性訴求・フォロワー獲得 | 25% |
| **DOOH/OOH紹介** | 街中の広告実例、設置風景、仕組み解説 | 差別化・認知拡大 | 20% |
| **会社・チーム紹介** | メンバー紹介、社内の雰囲気、日常 | 親近感・ブランド好感度 | 15% |
| **業界トレンド** | 広告業界ニュース、マーケ最新動向 | 権威性・エンゲージメント | 10% |

### プラットフォーム別投稿頻度

| プラットフォーム | 頻度 | 形式 |
|-----------------|------|------|
| Instagram フィード | 週3回 | カルーセル、静止画 |
| Instagram Reels | 週2回 | 30〜60秒の短尺動画 |
| Instagram Stories | 毎日 | アンケート、裏側、日常 |
| TikTok | 週2〜3回 | 15〜60秒の短尺動画（Reels転用＋オリジナル） |
| YouTube | 月2回 | 5〜10分の事例紹介・ノウハウ解説 |
| LINE公式 | 月2回 | ニュースレター、キャンペーン告知 |
| X | 週3〜5回 | テキスト中心、Instagram転用 |

## 5. KPI設定と測定方法

### KPI一覧

| KPI | 指標 | Month 1 | Month 2 | Month 3 | 測定ツール |
|-----|------|---------|---------|---------|-----------|
| **認知** | Instagram フォロワー数 | 300 | 800 | 1,500 | Instagram Insights |
| **認知** | TikTok フォロワー数 | - | 200 | 500 | TikTok Analytics |
| **認知** | YouTube 登録者数 | 30 | 60 | 100 | YouTube Studio |
| **認知** | 投稿リーチ数（月間） | 5,000 | 20,000 | 50,000 | 各プラットフォーム分析 |
| **関心** | エンゲージメント率 | 3% | 5% | 5% | 各プラットフォーム分析 |
| **関心** | プロフィールアクセス率 | 2% | 3% | 4% | Instagram Insights |
| **獲得** | LINE公式友だち数 | 50 | 120 | 200 | LINE Official Account Manager |
| **獲得** | SNS経由サイト流入数 | 100 | 400 | 1,000 | Google Analytics |
| **転換** | SNS経由問い合わせ数 | 1 | 5 | 15（累計） | CRM / 問い合わせフォーム |
| **転換** | SNS経由成約数 | 0 | 0 | 2（累計） | CRM |

### 測定・レポーティング方法

| 項目 | 頻度 | 内容 |
|------|------|------|
| 日次モニタリング | 毎日 | 各プラットフォームの投稿パフォーマンス確認（異常値検知） |
| 週次レビュー | 毎週金曜 | 週間KPI進捗、投稿別エンゲージメント分析、翌週コンテンツ調整 |
| 月次レポート | 月末 | KPI達成率、トップ/ワーストコンテンツ分析、改善施策、翌月計画 |
| 四半期総括 | 6月末 | 3ヶ月間のROI分析、次四半期戦略への提言 |

### 分析に使用するツール

- **Instagram Insights** / **TikTok Analytics** / **YouTube Studio**: 各プラットフォーム純正分析
- **Google Analytics 4**: SNS経由のサイト流入・コンバージョン計測（UTMパラメータ付与）
- **Googleスプレッドシート**: KPIダッシュボード（全プラットフォーム統合）

## 6. 予算案

### 3ヶ月間の予算総括

| 費目 | Month 1 | Month 2 | Month 3 | 合計 |
|------|---------|---------|---------|------|
| **SNS広告費** | 60,000円 | 100,000円 | 150,000円 | 310,000円 |
| **コンテンツ制作費** | 50,000円 | 50,000円 | 50,000円 | 150,000円 |
| **動画撮影・編集費** | 80,000円 | 60,000円 | 80,000円 | 220,000円 |
| **ツール利用料** | 10,000円 | 10,000円 | 10,000円 | 30,000円 |
| **予備費** | 20,000円 | 20,000円 | 20,000円 | 60,000円 |
| **月合計** | **220,000円** | **240,000円** | **310,000円** | **770,000円** |

### 費目の内訳

**SNS広告費**
- Instagram広告: 月40,000〜100,000円（ペルソナA・B向け、地域ターゲティング）
- TikTok広告: 月20,000〜50,000円（Month 2から開始）

**コンテンツ制作費**
- グラフィック素材（Canvaプロ等）: 月10,000円
- 写真素材・撮影小物: 月20,000円
- 外部ライター（必要時）: 月20,000円

**動画撮影・編集費**
- YouTube動画（月2本）: 撮影・編集費 1本30,000〜40,000円
- Reels/TikTok素材は社内撮影で対応（追加費用なし）

**ツール利用料**
- スケジューリングツール（Later等）: 月5,000円
- 分析補助ツール: 月5,000円

### 費用対効果の見通し

| 指標 | 算出根拠 | 3ヶ月後の見込み |
|------|---------|----------------|
| CPA（問い合わせ獲得単価） | 広告費310,000円 / 問い合わせ15件 | 約20,700円 |
| 成約単価 | 総予算770,000円 / 成約2件 | 約385,000円 |
| LTV比 | HIBURI顧客の平均LTV（仮定: 年間120万円） | ROI 約3.1倍（初年度） |

> **補足**: 成約単価385,000円は初期投資としては高めだが、顧客LTVを考慮すると初年度で十分に回収可能。Month 3以降はオーガニック流入の積み上げにより、CPAは継続的に低下する見込み。

## 補足: ブランドトーン&ガイドライン

SNS投稿全体で統一するトーン:

| 要素 | 方針 |
|------|------|
| **語調** | 親しみやすく、専門的すぎない。「です・ます」調ベース |
| **視覚** | HIBURIブランドカラーを基調に、明るく清潔感のあるデザイン |
| **価値提供** | 「中小企業の味方」として、実践的で役に立つ情報を発信 |
| **差別化メッセージ** | 「WEB広告だけじゃない。街の広告も、エンタメも。全部まとめて、あなたの集客を変える。」 |
| **ハッシュタグ戦略** | 固定: #HIBURI #中小企業マーケティング #クロスメディア / 投稿別: 業種・施策に応じたタグ5〜10個 |
