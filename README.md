# hiburi-tools

株式会社HIBURI ツール管理リポジトリ

## 組織構造

1人社長（意思決定権者） → 秘書（Claude Code） → 9部門長（Claude Code Agent）の指示委譲型組織です。
各部門のアウトプットは秘書が取りまとめてSlackで社長に報告し、社長のフィードバックを各部門に伝達します。

詳細は [組織図ドキュメント](docs/organization-chart.md) を参照してください。

| 区分 | 部門 | 管轄 |
|------|------|------|

| 事業 | 開発部 | ソフトウェア開発・技術選定 |
| 事業 | 営業部 | 顧客開拓・提案書・契約管理 |
| 事業 | マーケティング部 | 市場調査・広告・コンテンツ |

| 管理 | 経理・財務部 | 会計・予算・税務 |
| 基盤 | 人事・組織開発部 | 採用・育成・評価・組織開発 |
