# hiburi-tools

株式会社HIBURI ツール管理リポジトリ

## 組織構造

1人社長（意思決定権者） → 秘書（Claude Code） → 7部門長（Claude Code Agent）の指示委譲型組織です。
各部門のアウトプットは秘書が取りまとめてSlackで社長に報告し、社長のフィードバックを各部門に伝達します。

詳細は [組織図ドキュメント](docs/organization-chart.md) を参照してください。

## 部門一覧

| 部門 | 管轄 |
|------|------|
| 経営企画部 | 事業戦略・計画策定・KPI管理 |
| 開発部 | ソフトウェア開発・技術選定 |
| 営業部 | 顧客開拓・提案書・契約管理 |
| マーケティング部 | 市場調査・広告・コンテンツ |
| 総務部 | 社内規程・法務・コンプライアンス |
| 経理・財務部 | 会計・予算・税務 |
| カスタマーサポート部 | 顧客対応・FAQ・満足度向上 |
